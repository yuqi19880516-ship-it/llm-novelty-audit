# 人工金标准编码 — 码本与说明

这是预注册要求的**人工金标准 κ**。你（和/或学生）独立、盲态地手工编码,用来检验"机器编码器"是否真的对（**人–机效度**）。机器侧的可重复性（机器间 Fleiss κ=0.94）已做完;这一步只能由**人**来做。

## 你要判什么

对 156 条"药–病"假设,**仅依据所给摘要**,判定它是 **L0** 还是 **L1**:

- **L0（复述）**：≥1 篇摘要**明确**把该**药**当作该**病**的治疗/疗法/治疗候选——提出、推荐、报告疗效，或开展临床试验。
  - 典型信号:"X治疗Y""X是Y的候选药/重定位药""X用于Y的II/III期试验""X改善/缓解/减轻Y""X对Y有效"。
- **L1（既知重组）**：药与病在摘要里**共现**，但**没有任何一篇**明确把该药当作该病的治疗提出。常见情形:
  - 药只是**对照药**、或病只是**合并症/共病**;
  - 只提**机制/通路**而无治疗主张;
  - **流行病学共现**（如"用该药的人群Y风险更低"——属风险关联,不算治疗提出）;
  - 药被描述为该病的**诱因/副作用**（方向相反）。

### 判定铁律
1. **从严**：证据不足、含糊、只是"暗示"或"类别泛指（如'JAK抑制剂类'而未点名该药）" → 判 **L1**。
2. **只看摘要**：不要用你脑子里已知的医学知识,不要去查 PubMed/Google。只判"这几篇摘要里有没有明说"。
3. **无摘要的条目**（共现数极低、无摘要）→ 判 **L1**（文献里几乎不存在该共现,谈不上"早已提出"）。
4. **盲态**：不要去看机器的判定结果（见下）。先判完再说。
